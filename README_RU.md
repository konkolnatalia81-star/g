# TRUST CHECK — версия с сервером

В этой версии код доступа проверяется **на сервере**, а не в JavaScript браузера. В интерфейсе код нигде не показывается. История хранится в `data/history.json` на сервере и доступна только после успешного входа.

## Запуск на компьютере

1. Установи Node.js 18 или новее.
2. Распакуй архив и открой терминал в папке проекта.
3. Установи зависимости: `npm install`
4. Задай переменные окружения:
   - `ADMIN_CODE` — твой секретный код (задаётся только в настройках сервера, не в файлах сайта).
   - `SESSION_SECRET` — длинная случайная строка для защиты сессий.
   - `DATA_DIR` — папка для сохранения истории (необязательно).
5. Запусти: `npm start`
6. Открой `http://localhost:3000`.

## Публикация в интернете

Нужен Node.js-хостинг с постоянным диском (persistent disk/volume), подключённым к папке `data`.
- Build command: `npm install`
- Start command: `npm start`
- Добавь переменные `ADMIN_CODE` и `SESSION_SECRET` в Environment/Secrets на хостинге.
- Подключи постоянный диск и укажи `DATA_DIR` как путь к нему, например `/var/data`.

**Важно:** не вставляй секретный код в `public/app.js`, `public/index.html` или публичный репозиторий. Установи его только в приватных переменных окружения хостинга. Для реального использования включи HTTPS. Если хостинг не поддерживает постоянный диск, история может пропасть после перезапуска.

Проверки содержат имена и личные ответы. Храни доступ к панели и ссылке только у тех, кому доверяешь. Оценка теста — развлекательная, не объективная оценка дружбы.
